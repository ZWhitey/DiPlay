# Android 6 recovery status

Reconstructed from retained work notes, on branch android6/mtk-hardware. This is not a byte-for-byte restoration of the lost source.

Restored locally from retained artifacts: fix3, perf1, perf2 APKs. Their runtime certificate/identity assets remain inside the original APK; do not commit credentials to this public repository.

Reconstructed functionality:
- Bonjour interface mDNS bind conflict falls back to Android system NSD, with backend diagnostics and cleanup of partially opened JmDNS instances.
- Native Conscrypt 2.7.0 ChaCha20-Poly1305 fallback without global provider registration; BouncyCastle remains the fallback.
- Reused screen-stream header and decoder output BufferInfo; allocation-free queue accounting.
- Validated Annex B direct writes into codec input buffers.
- Android 6 low-memory default direct surface output, preserving explicit saved preferences.

Not recovered: original exact fix3/perf1/perf2 source, original signing private key, original full CI/stress logs and emulator images/tool caches. A signing private key cannot be extracted from a signed APK. The reconstructed source retains the fix2 application id; it must not be advertised as a drop-in update for perf2.

Validation: public credential check and git diff --check pass. Full required CI was attempted and failed before task execution because Gradle 9.5.0 download reported Network is unreachable. New tests have not run. Device hardware decoding and 30 FPS have not been verified.

Reproduction prerequisites: JDK 25, Gradle 9.5.0, Android platform 37.0, build tools 36.0.0, NDK 28.2.13676358, dependency network access. Existing upstream Android CI provisions these tools. Runtime authentication input and signing keys must be provided privately.
